# Email Archive Indexer — 用户指南

一款无需安装的 Windows 便携程序，可以快速查找和整理 Outlook 邮件备份文件 (.msg / .eml)，并自动从 Outlook 备份邮件。

## 1. 入门

1. 将 `EmailIndexer.exe` 这一个文件放在任意位置（例如桌面或“文档”）。无需安装。
2. 双击运行。
   - 如果出现 **“Windows 已保护你的电脑”** → **更多信息** → **仍要运行**
   - 如果仍然无法运行：右键单击该文件 → **属性** → 勾选底部的 **解除锁定** → 确定 → 再次运行
3. 单击 **更改文件夹**，选择邮件备份文件夹。（也可以从文件资源管理器将文件夹拖到窗口中。）
4. 首次运行时会读取整个文件夹。之后只读取有更改的文件，因此几秒钟即可打开。

> 请勿以管理员身份运行。如果它与 Outlook 的权限级别不同，Outlook 备份将无法使用。

**语言：** 应用默认以英语启动。若要更改，请打开 **设置** → **Language / 언어**，选择一种语言，然后重新启动应用。每种语言都以其自身名称列出（English、한국어、Español、Français、日本語、简体中文）。

## 2. 主窗口

| 区域 | 功能 |
|---|---|
| 顶部 | 备份文件夹、**扫描 (F5)**、**Outlook 备份**、**设置**、**帮助 (F1)** |
| 筛选（左侧） | 日期 · 收到/发出 · 附件 · 会议（会议邀请/已接受/已拒绝/暂定/已取消） · 状态（重复/相似/错误/未规范化） · 格式 · 文件夹 · 前 30 位发件人 |
| 搜索框 | 同时搜索主题、人员、正文和附件名。多个词 = 必须全部匹配，`"引号"` = 完全匹配短语。使用旁边的按钮缩小范围 |
| 列表 | 单击列标题进行排序。灰色 = 重复，橙色 = 相似，红色 = 读取错误 |
| 底部 | 总数 · 显示数 · 已选数，扫描结果 |

## 3. 日常操作

| 要执行的操作 | 操作方法 |
|---|---|
| 快速阅读邮件 | 双击或按 Enter → 在格式视图和文本视图之间切换，使用 ◀ ▶ 查看上一封/下一封 |
| 在 Outlook 中打开 | Ctrl+O 或 **打开** |
| 选择多封邮件 | Ctrl/Shift + 单击，Ctrl+A |
| 转到搜索框 | Ctrl+F（Esc 清除搜索） |
| 右键菜单 | 预览 · 打开 · 在文件夹中显示 · 复制路径 · 规范化文件名 · 移动所选项 · 移到回收站 · 仅显示此发件人 |
| 了解功能用法 | F1 或 **帮助 (F1)** |

## 4. 整理文件

- **规范化文件名**：将文件重命名为 `260823_175434_张伟 [销售部]_第35周团队议程_无附件.msg` 格式。
  - 收到的邮件使用接收时间；发出的邮件使用发送时间。
  - 末尾的附件标记随应用语言而定（中文为 `_有附件`/`_无附件`）。已按任意语言规范化的文件保持不变。
  - 如果未选择任何邮件，则包括列表中显示的所有邮件。
  - 在进行任何更改之前，会先显示“更改前 → 更改后”表格。在同一窗口中单击 **撤销上次规范化** 可恢复原始名称。
  - 主题中的 `: / ?` 等字符会变为外观相似的全角字符（`： ／ ？`）。
- **移动所选项**：将文件移动到你选择的文件夹。如果存在同名文件，会添加 ` (2)`。
- **删除所选项 (Del)**：将文件移到 **回收站**，可以从中还原。
- **清理重复项**：先在表格中显示已确认为同一邮件的文件，然后将其移到回收站。每组保留一个原件。
- **自动删除重复项**：如果复制进来的邮件已存在，下次扫描时新添加的副本会自动移到回收站。
  - 首次扫描时不会自动删除任何文件，只会标记重复项。
  - 从回收站还原的文件不会再次被删除。
  - 仅重命名或移动到其他文件夹的文件不视为重复。

## 5. Outlook 自动备份

1. 如果 Outlook (经典版) 未运行，会自动启动。如果出现配置文件选择窗口，请选择你的配置文件。（不支持新版 Outlook。）
2. **Outlook 备份** → 选择范围（自上次备份以来 / 最近 N 天 / 全部） → **开始备份**
3. 收件箱和已发送邮件中的邮件会以规范化的名称 **直接保存在备份文件夹中**（不创建子文件夹）。之后你可以自行将文件移到子文件夹中，扫描仍会找到所有文件。
4. 已备份的邮件将被跳过。Outlook 中的原始邮件不会被更改。
5. 如果 Outlook 显示“某个程序正试图访问…”，请单击 **允许**。

## 6. 疑难解答

| 问题 | 解决方法 |
|---|---|
| Outlook 备份：“无法连接” | 以普通方式（双击，不要以管理员身份）重新启动 Outlook 和此程序 |
| Outlook 备份：“新版 Outlook”提示 | 关闭 Outlook 右上角的 **新版 Outlook** 开关，切换回经典版 |
| 列表中出现红色“错误”文件 | 文件已损坏或不是邮件文件。原因显示在“主题”列中 |
| 程序运行异常 | 将 **设置** → **环境检查** 的结果和下列日志文件发送给你的技术支持联系人 |

**日志文件**（报告问题时请附上；日志始终以英语写入）
- `备份文件夹\.emailindex\last-scan.log` — 上次扫描结果和错误原因
- `备份文件夹\.emailindex\actions.log` — 重命名、移动和删除记录
- `备份文件夹\.emailindex\outlook-backup.log` — Outlook 备份记录
- `%APPDATA%\EmailIndexer\error.log` — 意外错误

隐藏的 `.emailindex` 文件夹是用于快速打开列表的缓存。删除它不会影响你的邮件；下次运行时会重新生成。（删除后，下一次扫描会像首次扫描一样不自动删除重复项，并且 Outlook 备份的“自上次备份以来”起点会丢失。）
