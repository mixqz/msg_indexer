# Email Archive Indexer — ユーザー ガイド

Outlook のメール バックアップ ファイル (.msg / .eml) をすばやく見つけて整理し、Outlook からメールを自動的にバックアップできる、インストール不要の Windows 用ポータブル プログラムです。

## 1. はじめに

1. `EmailIndexer.exe` ファイル 1 つを好きな場所 (デスクトップやドキュメントなど) に置きます。インストールは不要です。
2. ダブルクリックして実行します。
   - **「Windows によって PC が保護されました」** と表示された場合 → **詳細情報** → **実行**
   - それでも実行できない場合: ファイルを右クリック → **プロパティ** → 下部の **許可する** をチェック → OK → もう一度実行します
3. **フォルダーの変更** をクリックして、メールのバックアップ フォルダーを選択します (エクスプローラーからウィンドウにフォルダーをドラッグすることもできます)。
4. 初回はフォルダー全体を読み込みます。2 回目以降は変更されたファイルだけを読み込むため、数秒で開きます。

> 管理者として実行しないでください。Outlook と異なる権限レベルで実行すると、Outlook バックアップが動作しません。

**言語:** アプリは英語で起動します。変更するには、**設定** → **Language / 언어** を開いて言語を選び、アプリを再起動します。各言語はその言語自身の名前で表示されます (English、한국어、Español、Français、日本語、简体中文)。

## 2. メイン ウィンドウ

| 領域 | 内容 |
|---|---|
| 上部 | バックアップ フォルダー、**スキャン (F5)**、**Outlook バックアップ**、**設定**、**ヘルプ (F1)** |
| フィルター (左側) | 期間 · 受信 / 送信 · 添付ファイル · 会議 (会議出席依頼 / 承諾 / 辞退 / 仮承諾 / キャンセル) · 状態 (重複 / 類似 / エラー / 未正規化) · 形式 · フォルダー · 差出人 上位 30 |
| 検索ボックス | 件名、人物、本文、添付ファイル名をまとめて検索します。複数の語 = すべてに一致、`"引用符"` = 完全一致。横のボタンで検索範囲を絞り込めます |
| 一覧 | 列見出しをクリックすると並べ替えます。灰色 = 重複、オレンジ = 類似、赤 = 読み取りエラー |
| 下部 | 合計 · 表示 · 選択の件数、スキャン結果 |

## 3. よく使う操作

| やりたいこと | 操作 |
|---|---|
| メールをすばやく読む | ダブルクリックまたは Enter → 書式付き表示とテキスト表示を切り替え、◀ ▶ で前 / 次のメール |
| Outlook で開く | Ctrl+O または **開く (Ctrl+O)** |
| 複数のメールを選択する | Ctrl / Shift + クリック、Ctrl+A |
| 検索ボックスへ移動する | Ctrl+F (Esc で検索をクリア) |
| 右クリック メニュー | プレビュー · 開く (Outlook) · フォルダーに表示 · パスのコピー · ファイル名の正規化 · 選択項目を移動 · ごみ箱に移動 · この差出人のみ表示 |
| 機能の使い方を確認する | F1 または **ヘルプ (F1)** |

## 4. ファイルの整理

- **ファイル名の正規化**: ファイル名を `260823_175434_Alex Kim [Sales Team]_W35 team agenda_添付無.msg` の形式に変更します。
  - 受信メールは受信日時、送信メールは送信日時を使います。
  - 末尾の添付の表示はアプリの言語に従います (日本語は `_添付有` / `_添付無`)。いずれかの言語で既に正規化されたファイルはそのまま残します。
  - 何も選択していない場合は、一覧に表示されているすべてのメールが対象になります。
  - 変更の前に「変更前 → 変更後」の表が表示されます。同じウィンドウの **前回の正規化を元に戻す** で元の名前に戻せます。
  - 件名に含まれる `: / ?` などの文字は、見た目が似た全角文字 (`： ／ ？`) に置き換えます。
- **選択項目を移動**: 選んだフォルダーにファイルを移動します。同じ名前のファイルがある場合は ` (2)` が付きます。
- **選択項目を削除 (Del)**: ファイルを **ごみ箱** に移動します。ごみ箱から元に戻せます。
- **重複の整理**: 同じメールと確認されたファイルを表で示してから、ごみ箱に移動します。各グループの元のファイルは 1 つ残します。
- **重複の自動削除**: 既にあるメールをバックアップ フォルダーにもう一度コピーすると、次回のスキャンで新しく追加されたほうが自動的にごみ箱に移動されます。
  - 最初のスキャンでは自動的に削除せず、重複として表示するだけです。
  - ごみ箱から元に戻したファイルが再び削除されることはありません。
  - 名前を変更しただけのファイルや、別のフォルダーに移動しただけのファイルは重複と見なしません。

## 5. Outlook の自動バックアップ

1. Outlook (クラシック) が起動していない場合は自動的に起動します。プロファイルの選択画面が表示されたら、プロファイルを選択してください (新しい Outlook には対応していません)。
2. **Outlook バックアップ** → 範囲を選択 (前回のバックアップ以降 / 過去 N 日間 / すべて) → **バックアップ開始**
3. 受信トレイと送信済みアイテムのメールが、正規化された名前で **バックアップ フォルダーに直接** (サブフォルダーを作らずに) 保存されます。後でファイルをサブフォルダーに移動してもかまいません。スキャンですべて見つかります。
4. バックアップ済みのメールはスキップします。Outlook 内の元のメールはそのまま残ります。
5. Outlook に「プログラムが…にアクセスしようとしています」と表示されたら、**許可** をクリックしてください。

## 6. トラブルシューティング

| 問題 | 対処 |
|---|---|
| Outlook バックアップ:「接続できません」 | Outlook とこのプログラムを両方とも通常の方法で (管理者としてではなく、ダブルクリックで) 起動し直してください |
| Outlook バックアップ:「新しい Outlook」のメッセージ | Outlook の右上にある **新しい Outlook** スイッチをオフにして、クラシックに戻してください |
| 一覧に赤い「エラー」のファイルがある | ファイルが破損しているか、メール ファイルではありません。理由は件名の列に表示されます |
| 動作がおかしい | **設定** → **環境チェック** の結果と、以下のログ ファイルをサポート担当者に送ってください |

**ログ ファイル** (問題を報告するときに添付してください。ログは常に英語で記録されます)
- `バックアップ フォルダー\.emailindex\last-scan.log` — 前回のスキャン結果とエラーの理由
- `バックアップ フォルダー\.emailindex\actions.log` — 名前の変更、移動、削除の履歴
- `バックアップ フォルダー\.emailindex\outlook-backup.log` — Outlook バックアップの履歴
- `%APPDATA%\EmailIndexer\error.log` — 予期しないエラー

隠しフォルダー `.emailindex` は、一覧をすばやく開くためのキャッシュです。削除してもメールには影響せず、次回の実行時に一から再作成されます (削除した後は、初回スキャンと同様に重複の自動削除が 1 回スキップされ、Outlook バックアップの「前回のバックアップ以降」の基準も失われます)。
