# Email Archive Indexer 사용 안내

Outlook 메일 백업 파일(.msg / .eml)을 빠르게 찾고, 정리하고, Outlook에서 자동으로 백업하는 무설치 프로그램입니다.

## 1. 시작하기

1. `EmailIndexer.exe` 파일 하나를 원하는 곳(예: 바탕화면, 문서 폴더)에 둡니다. 설치는 필요 없습니다.
2. 더블클릭해서 실행합니다.
   - **"Windows의 PC 보호"** 창이 뜨면 → **[추가 정보]** → **[실행]**
   - 그래도 실행되지 않으면: 파일 오른쪽 클릭 → **속성** → 아래쪽 **"차단 해제"** 체크 → 확인 → 다시 실행
3. **[폴더 변경]**을 눌러 메일 백업 폴더를 고릅니다. (탐색기에서 폴더를 창으로 끌어다 놓아도 됩니다)
4. 처음에는 폴더 전체를 읽습니다. 다음부터는 바뀐 파일만 읽어 몇 초 안에 열립니다.

> 관리자 권한으로 실행하지 마세요. Outlook과 권한이 다르면 Outlook 백업이 되지 않습니다.

## 2. 화면

| 영역 | 설명 |
|---|---|
| 위쪽 | 백업 폴더, [스캔(F5)], [Outlook 백업], [설정] |
| 왼쪽 필터 | 기간 · 받음/보냄 · 첨부 · 일정(초대/수락/거절/미정/취소) · 상태(중복/유사/오류/미정규화) · 형식 · 폴더 · 발신자 TOP 30 |
| 검색창 | 제목·사람·본문·첨부파일명을 한 번에 검색. 여러 단어 = 모두 포함, `"따옴표"` = 구문 그대로. 옆 버튼으로 범위 좁히기 |
| 목록 | 열 제목 클릭 = 정렬. 회색 = 중복, 주황 = 유사, 빨강 = 읽기 오류 |
| 아래 | 전체 · 표시 · 선택 개수, 스캔 결과 |

## 3. 자주 쓰는 동작

| 하고 싶은 것 | 방법 |
|---|---|
| 내용 빠르게 보기 | 더블클릭 또는 Enter → [서식 보기]/[텍스트 보기] 전환, ◀ ▶로 이전/다음 |
| Outlook으로 열기 | Ctrl+O 또는 [열기] |
| 여러 개 선택 | Ctrl/Shift + 클릭, Ctrl+A |
| 검색창으로 이동 | Ctrl+F (Esc = 검색어 지우기) |
| 오른쪽 클릭 | 보기 · 열기 · 폴더에서 보기 · 경로 복사 · 정규화 · 이동 · 삭제 · 이 발신자만 보기 |

## 4. 파일 정리

- **파일명 정규화**: `260823_175434_Alex Kim [Sales Team]_W35 team agenda_첨부X.msg` 형식으로 이름을 바꿉니다.
  - 받은 메일은 받은 시각, 보낸 메일은 보낸 시각을 씁니다.
  - 선택한 것이 없으면 지금 목록에 보이는 전체가 대상입니다.
  - 실행 전에 '변경 전 → 후' 표로 확인합니다. 같은 창의 **[마지막 정규화 되돌리기]**로 원래 이름으로 돌릴 수 있습니다.
  - 제목의 `: / ?` 같은 문자는 모양이 같은 전각 문자(`： ／ ？`)로 바뀝니다.
- **선택 이동**: 고른 폴더로 옮깁니다. 같은 이름이 있으면 ` (2)`가 붙습니다.
- **선택 삭제 (Del)**: **휴지통**으로 보냅니다. 휴지통에서 복원할 수 있습니다.
- **중복 정리**: 같은 메일로 확인된 파일을 표로 보여준 뒤 휴지통으로 보냅니다. 묶음마다 원본 1개는 남깁니다.
- **자동 중복 제거**: 이미 있는 메일을 다시 복사해 넣으면, 다음 스캔 때 새로 들어온 쪽이 자동으로 휴지통에 갑니다.
  - 처음 스캔할 때는 자동으로 지우지 않고 '중복' 표시만 합니다.
  - 휴지통에서 복원한 파일은 다시 지우지 않습니다.
  - 이름만 바꾸거나 다른 폴더로 옮긴 파일은 중복으로 보지 않습니다.

## 5. Outlook 자동 백업

1. Outlook(classic)이 꺼져 있으면 자동으로 실행됩니다. 프로필 선택 창이 뜨면 선택해 주세요. (새 Outlook은 지원하지 않습니다)
2. **[Outlook 백업]** → 기간 선택(마지막 백업 이후 / 최근 N일 / 전체) → **[백업 시작]**
3. 받은편지함·보낸편지함 메일 모두 **백업 폴더에 바로**(하위 폴더 없이) 정규화된 이름으로 저장됩니다. 저장 후 하위 폴더로 직접 옮겨도 스캔하면 모두 찾아냅니다.
4. 이미 백업된 메일은 건너뜁니다. Outlook의 원본 메일은 그대로 남습니다.
5. Outlook에 "다른 프로그램이 접근하려고 합니다" 창이 뜨면 **허용**을 누르세요.

## 6. 문제가 생기면

| 증상 | 해결 |
|---|---|
| Outlook 백업: "연결할 수 없습니다" | Outlook과 이 프로그램을 둘 다 일반 권한(더블클릭)으로 다시 실행 |
| Outlook 백업: "새 Outlook" 안내 | Outlook 오른쪽 위 '새 Outlook' 스위치를 꺼서 classic으로 전환 |
| 목록에 빨간 '오류' 파일 | 손상됐거나 메일 형식이 아닌 파일. 제목 칸에 사유 표시 |
| 이상하게 동작함 | [설정] → [실행 환경 점검] 결과와 아래 기록 파일을 담당자에게 전달 |

**기록 파일** (문제 보고 시 첨부)
- `백업폴더\.emailindex\last-scan.log` — 마지막 스캔 결과와 오류 사유
- `백업폴더\.emailindex\actions.log` — 이름변경·이동·삭제 기록
- `백업폴더\.emailindex\outlook-backup.log` — Outlook 백업 기록
- `%APPDATA%\EmailIndexer\error.log` — 예상하지 못한 오류

`.emailindex` 숨김 폴더는 목록을 빨리 여는 데 쓰는 캐시입니다. 지워도 메일에는 영향이 없고, 다음 실행 때 처음부터 다시 만듭니다. (단, 지우면 첫 스캔처럼 자동 중복 제거가 한 번 쉬고, Outlook '마지막 백업 이후' 기준도 사라집니다)
