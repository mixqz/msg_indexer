## Email Archive Indexer v1.1.0 — multilingual release

A portable Windows program to search, organize and back up Outlook mail files (.msg / .eml). One exe, no installation, no administrator rights, no network access.

### New
- **6 languages:** English (default), 한국어, Español, Français, 日本語, 简体中文 — Settings → Language / 언어.
- File-name attachment marker follows the language (`_AttY`/`_AttN`, `_첨부O`/`_첨부X`, `_添付有`/`_添付無`, `_有附件`/`_无附件`). Files already normalized in any language are left as they are.
- Old mail without a charset is read with your PC region's code page (Japanese, Chinese, Cyrillic, Central European…), not only Korean.
- Help window (F1) with 12 topics, redesigned Windows 11-style look, new app icon.
- Outlook backup saves straight into the backup folder and starts Outlook (classic) if it isn't running.
- Clearer confirmations (buttons say what will happen), empty-list hints, notice when duplicates were sent to the Recycle Bin.

### Removed
- CSV export.

### Upgrading from 1.0.x
Replace `EmailIndexer.exe` with the new one; your cache and settings are kept. The app now starts in **English**, because older settings have no language entry. To switch back, open **Settings → Language / 언어**, choose your language (e.g. 한국어), click **Save** and restart the app. You only need to do this once.

1.0.x에서 업그레이드하면 처음에는 **영어**로 열립니다. **Settings → Language / 언어**에서 **한국어**를 고르고 **Save**를 누른 뒤 다시 실행하세요. 한 번만 하면 됩니다.

### Known limitations
- Translations were written with AI assistance and reviewed for meaning, but not yet by native speakers. Corrections are welcome — see CONTRIBUTING.md.
- Outlook backup needs Outlook (classic); the new Outlook is not supported.
