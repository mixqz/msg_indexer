# Windows 실기 테스트 체크리스트 (회사 PC)

Mac(Docker·Mono)에서 확인할 수 없었던 항목 위주. 결과(✅/❌ + 메모)를 채워서 전달해 주세요.
**반드시 원본이 아닌 복사본 폴더로 먼저 테스트하세요.** (예: 백업 폴더 일부를 `바탕화면\테스트백업`에 복사)

## A. 실행
| # | 확인 | 결과 |
|---|---|---|
| A1 | exe 더블클릭으로 실행됨 (관리자 권한 요청 없음) | |
| A2 | [설정] → [실행 환경 점검]: Windows 11, .NET 4.8 이상, "일반 사용자" 표시 | |
| A3 | 글자 깨짐 없음, 화면 배율 125~150%에서 버튼·목록이 잘리지 않음 | |

## B. 스캔·캐시
| # | 확인 | 결과 |
|---|---|---|
| B1 | 테스트 폴더 선택 → 모든 msg/eml이 목록에 나옴 (하위 폴더 포함), 개수 = 탐색기 개수 | |
| B2 | 첫 스캔 시간: ____초 (파일 ____개) | |
| B3 | 앱을 닫았다 다시 열면 목록이 즉시 표시되고 "신규 0" | |
| B4 | 발신일·발신자·제목·첨부·일정 종류가 Outlook에서 연 내용과 일치 (msg 5개, eml 5개 확인) | |
| B5 | 회의 초대/수락/거절 메일의 '일정' 칸 표시가 맞음 | |
| B6 | 서명 로고만 있는 메일은 첨부 칸이 비어 있음 | |

## C. 검색·필터·보기
| # | 확인 | 결과 |
|---|---|---|
| C1 | 한글 검색(제목/발신자/본문/첨부파일명) 결과가 맞음 | |
| C2 | 기간·첨부·일정·폴더·발신자 필터, [초기화] | |
| C3 | 미리보기: 서식 보기에서 표·서명 이미지 표시, 텍스트 보기 전환, 이전/다음 | |
| C4 | Ctrl+O / [Outlook으로 열기]로 실제 Outlook에서 열림 | |

## D. 파일 관리 (복사본 폴더에서!)
| # | 확인 | 결과 |
|---|---|---|
| D1 | 파일명 정규화: 미리보기 확인 → 실행 → 이름이 규칙대로 바뀜, 목록 자동 갱신 | |
| D2 | [마지막 정규화 되돌리기]로 원래 이름 복귀 | |
| D3 | 선택 이동: 파일이 옮겨지고 목록 갱신 | |
| D4 | 선택 삭제: **휴지통**에 들어감 (복원 가능) | |
| D5 | 기존 메일 하나를 복사해 넣고 [스캔] → 복사본이 자동으로 휴지통에 감, 원본은 남음 | |
| D6 | D5의 복사본을 휴지통에서 복원 → [스캔] 해도 다시 지워지지 않음 ('중복' 표시만) | |
| D7 | [중복 정리] 미리보기 → 실행 → 원본 1개씩 남음 | |

## E. Outlook 백업 (Outlook classic 실행 상태)
| # | 확인 | 결과 |
|---|---|---|
| E1 | [Outlook 백업] → 기간 "최근 7일" → [백업 시작] → 저장 개수 > 0 | |
| E2 | 백업 폴더 바로 아래(하위 폴더 없이)에 정규화된 이름으로 저장, Outlook 원본은 그대로 | |
| E3 | 저장된 msg를 더블클릭하면 Outlook에서 정상으로 열림 (한글 깨짐 없음) | |
| E4 | 바로 한 번 더 백업 → 모두 "건너뜀", 저장 0 | |
| E5 | 보낸편지함 메일이 목록에서 '보냄'으로 표시 | |
| E6 | Outlook을 끈 상태에서 [백업 시작] → Outlook(classic)이 자동으로 켜지고 백업 진행 | |
| E7 | 실패가 있으면 사유 목록 캡처 + `.emailindex\outlook-backup.log` 전달 | |

문제가 있으면 해당 번호와 함께 `.emailindex\last-scan.log`, `actions.log`, `outlook-backup.log`, `%APPDATA%\EmailIndexer\error.log`를 보내 주세요.
